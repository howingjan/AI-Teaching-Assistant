# ADR-002：结构化输出 + 引用校验，而不是自由文本

- **状态**：已采纳（Phase 2）
- **日期**：2026-08
- **背景**：早期直接用大模型生成一段长文本，无法稳定展示、校验、导出和评测。
- **决策**：每个教学任务绑定固定的 JSON 输出结构（学习目标、前置知识、术语、例题、练习、引用……），模型输出后用 `CitationValidator` 独立校验引用是否指向真实文档与页码。
- **理由**：
  1. 结构化字段可被自动校验（测试断言各字段是否完整）；
  2. 引用被绑定到真实 chunk，模型无法自由编造页码；
  3. 无效引用被丢弃并写入 `needs_review`，把“幻觉”转化为“需要老师确认”的显式信号。
- **代价**：模型必须遵守 JSON schema，偶尔输出解析失败；用 `parse_json_response` 按括号配对容错解析（2026-09 起无 mock，未配置 key 直接报错）。
- **关键教训**：校验引用准确率时，应以模型的**原始输出**为据独立复算，而不是直接采用 pipeline 过滤后的结果，否则会高估质量（此逻辑由 `tests/` 覆盖）。
