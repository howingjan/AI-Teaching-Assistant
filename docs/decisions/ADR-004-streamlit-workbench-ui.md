# ADR-004：第一版采用本地 Streamlit Web 应用作为界面

- **状态**：已采纳（Phase 4）
- **日期**：2026-08
- **背景**：产品规划第 5 节要求“不要只提供一个空白聊天框”，应直接呈现资料库、教学任务入口和生成结果区。
- **决策**：用 Streamlit 构建本地教师工作台（`app.py`），四个区域：📚 资料库（上传/索引统计/检索可视化）、🎯 教学任务（五个任务入口）、📄 生成结果（结构化展示/来源展开/编辑/导出 MD·HTML·JSON）、📊 评测与失败案例。
- **理由**：
  1. 与 Python 核心栈同语言、零前后端分离成本，最快验证产品闭环；
  2. 技术选型不应先于产品验证（规划 5 节）；Streamlit 足够支撑 MVP；
  3. 数据与 API key 都留在本地，符合隐私边界（第 11 节）。
- **代价**：Streamlit 不适合复杂实时协作；若将来做教师团队/SaaS（10.2），再迁移到 React + API。
- **后续**：导出格式当前为 Markdown/HTML/JSON；Word/PDF 作为后续增强。
