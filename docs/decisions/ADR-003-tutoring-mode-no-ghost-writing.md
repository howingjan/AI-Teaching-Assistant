# ADR-003：作业讲题默认使用教学辅导模式（分层提示、不代写）

- **状态**：已采纳（Phase 3）
- **日期**：2026-08
- **背景**：作业与真题讲题如果直接输出完整答案，学生会把结果当作可提交物，违背教学与学术诚信目标。
- **决策**：`problem_solving` 任务输出“分步解题思路 + 分层提示（Level 1 最隐晦、逐级接近答案）+ 参考解题方向”，默认不生成可直接提交的完整答案。
- **理由**：
  1. 产品定位是“讲解”而不是“代写”，符合学术诚信边界（产品规划第 11 节）；
  2. 分层提示可以逐步引导学生，与“苏格拉底式提问”的后续方向一致（9.1）；
  3. 评测中加入“分层提示是否至少 2 级”的专项检查，防止退化成一次性给答案。
- **代价**：老师希望直接给答案时会觉得绕；通过 `goal` 参数保留灵活性（仍默认不代写）。
