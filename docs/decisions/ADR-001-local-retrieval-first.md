# ADR-001：先做可解释的本地检索，而不是一上来就上向量数据库

- **状态**：已采纳（Phase 1）
- **日期**：2026-08
- **背景**：课程资料规模小（一门课几份 PDF、数百个片段），但老师需要看到“答案来自哪一页”。
- **决策**：第一阶段用 TF-IDF / 关键词检索返回 top-k 片段，配合页面级元数据；随后引入多语言 embedding（multilingual-e5-small）作为默认，TF-IDF 保留为可切换基线与调试手段。
- **理由**：
  1. 本地、可解释、无需外部服务，容易调试、评测和演示；
  2. 中文查询匹配英文课件需要跨语言能力，embedding 解决了 Phase 1 的检索瓶颈；
  3. 向量数据库只有在数据量足够大、混合检索被离线评测证明更好时才引入。
- **代价**：embedding 需要 torch + 预训练模型（约 470MB），冷启动较慢；已通过向量缓存 `.npy` 缓解。
- **后续**：见 ADR-003（评测驱动）——任何检索升级都必须用引用准确率证明收益。
