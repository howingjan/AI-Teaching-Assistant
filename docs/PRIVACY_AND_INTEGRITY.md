# 隐私、版权与学术诚信说明

> 本文件对应产品规划第 11 节，说明系统如何处理数据、规避版权风险并守住学术诚信边界。**最终发布前请老师逐条确认。**

## 1. 数据与隐私

- **API key 不出代码、日志或导出材料**：`DEEPSEEK_API_KEY` 只从 `.env` 读取，从不写入索引、评测报告、`logs/usage.jsonl` 或任何导出的教学材料。
- **原始资料默认本地保存**：课程资料只存放在本地 `data/<course>/`，系统不上传到任何云端存储；删除 `data/<course>` 即完成删除。
- **避免上传学生个人信息**：请勿上传包含学生姓名、学号、邮箱等个人信息的资料；如确需处理，必须先获得学生同意并理解风险。
- **第三方模型的数据保留**：调用 DeepSeek 等第三方 API 时，提示内容会发送给模型供应商。若课程或机构对数据驻留有要求，请选择支持本地模型或私有化部署的方案（见产品规划 10.2）。
- **本地模型选项**：未配置 API key 时系统进入 mock 模式，数据完全离线。

## 2. 版权

- **不公开传播受版权保护的课程资料**：解析出的课件、作业、真题只用于老师本人备课，不通过本系统对外发布或分发。
- **索引是派生数据**：`data/index/*.json` 与 embedding 缓存是对原始资料的本地派生，仅用于检索；删除资料时应一并删除对应索引。
- **生成内容标注为草稿**：所有导出的教学材料都带有“草稿，需老师审核”标识；老师对最终内容及其版权负责。

## 3. 学术诚信

- **讲题不代写**：作业与真题讲题默认输出“分步思路 + 分层提示 + 参考解题方向”，不生成可直接提交的完整答案（见 ADR-003）。
- **引用必须可追溯**：重要结论都绑定到课程资料的具体文档与页码；找不到依据时系统明确告知“资料不足”，而不是编造。
- **Cheat sheet 只在允许时使用**：速查表草稿必须在课程与考试规则允许的前提下使用，老师负责遵守考场规定。
- **学生端边界**（未来开放学生功能时）：学生只基于老师选定的资料问答，采用逐步提示而非直接给答案。

## 4. 老师责任清单

- [ ] 审核所有生成内容后再用于课堂；
- [ ] 不把含学生个人信息的资料上传系统；
- [ ] 不对外公开受版权保护的课程资料；
- [ ] 遵守课程与考试的 cheat sheet / 作业提交规则；
- [ ] 确认第三方模型的数据使用政策可接受。
