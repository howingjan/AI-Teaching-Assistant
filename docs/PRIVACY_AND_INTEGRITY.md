# 隐私、版权与学术诚信说明

> 说明系统如何处理数据、规避版权风险并守住学术诚信边界。**首次使用前请老师阅读并确认。**

## 1. 数据与隐私

- **API key 不出代码、日志或导出材料**：`DEEPSEEK_API_KEY` 只从 `.env` 读取，从不写入索引、
  `logs/usage.jsonl` 或任何导出的教学材料。
- **本地存储**：课程资料与索引保存在本地 `data/`，不会上传到云端文件存储；
  删除 `data/<course>` 可删除课程资料和相应索引。
- **LLM 数据流**：检索与生成编排在本机运行；发送给配置的大模型 API（DeepSeek）的提示词
  可能包含课件原文。Docker 部署时本地文件通过 `./data` 卷挂载，不打包进镜像。
- **新旧课件比对**：比对需要将学校课件和补习课件的相关文本发送给配置的 DeepSeek API。
  页面开始任务前会要求教师明确确认；暂存文件、报告和修订 DOCX 保存在
  `data/course_updates/<task_id>/`，使用者应在任务完成后按组织的数据保留要求清理。
  资料库替换是独立的本地操作，需要单独确认；替换前的旧 PDF 保存在
  `data/course_update_backups/<course>/<backup_id>/` 以供回滚。修订版 PDF 使用本机
  LibreOffice 转换，不会因此把文件上传到第三方转换服务。
- **避免上传学生个人信息**：请勿上传含学生姓名、学号、邮箱等个人信息的资料；如确需处理，
  必须先获得同意并评估风险。
- **第三方模型的数据政策**：本系统为**真实生成**（无离线 mock）。使用前请确认 DeepSeek 等
  供应商的数据使用与保留政策符合你的要求；否则请自备/选择合规的 API 端点。

## 2. 版权

- **不公开传播受版权保护的课件**：解析的课件、作业、真题只用于老师本人备课，不通过本系统对外
  发布或分发。
- **索引是派生数据**：`data/index/*.json` 与向量缓存是课件的本地派生，仅用于检索；删除资料时
  应一并删除对应索引。
- **版本备份也是课件副本**：`data/course_update_backups/` 保存被替换的旧 PDF；请按与课程原件相同的
  隐私、版权和保留策略进行保护与清理。
- **生成内容标注为草稿**：导出的教学材料带有“草稿，需老师审核”标识；老师对最终内容与版权负责。

## 3. 学术诚信

- **讲题不代写**：作业与真题讲题输出“分步思路 + 分层提示 + 参考解题方向”，不生成可直接提交的
  完整答案（ADR-003）。
- **引用必须可追溯**：重要结论绑定到课件的具体文档与页码；找不到依据时系统明确提示“资料不足”，
  不会编造（ADR-002）。
- **学生端边界**（未来开放学生功能时）：学生只基于老师选定的资料问答，采用逐步提示而非直接给答案。

## 4. 老师责任清单

- [ ] 审核所有生成内容后再用于课堂；
- [ ] 不把含学生个人信息的资料上传系统；
- [ ] 不对外公开受版权保护的课程资料；
- [ ] 确认所配置的大模型 API 数据政策可接受。
